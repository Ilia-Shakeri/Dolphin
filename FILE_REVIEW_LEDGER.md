Every row records the full goal field set. The three compact fact columns list their named subfields in header order. A named subfield not stated in its compact cell has the recorded value `N/A`; for the test subfield this means `no direct automated test`. This default is used only when that concept does not apply to the row or no direct proof exists; it must not hide a known dependency, interface, entity, state change, security concern, test, or language/brand fact. The roadmap cell links the exact Phase 1 file-review gate; a more specific later-phase action remains in `Follow-up action`.
