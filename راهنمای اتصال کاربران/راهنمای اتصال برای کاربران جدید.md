# راه‌اندازی پنل دلفین روی کامپیوتر شرکت

این کار فقط یک بار انجام می‌شود. پس از آن پنل با دامنه باز می‌شود.

## فایل لازم

فایل زیر را فقط از مسئول فنی شرکت بگیرید:

```text
tiara-internal-root-ca.cer
```

فایل را داخل پوشه `Downloads` بگذارید.

هیچ فایل `.key` یا `.pem` دریافت یا نصب نکنید.

## اجرای دستور

۱. به Wi-Fi شرکت وصل شوید.

۲. منوی Start را باز کنید.

۳. عبارت `PowerShell` را جست‌وجو کنید.

۴. روی Windows PowerShell راست‌کلیک کنید.

۵. گزینه `Run as administrator` را بزنید.

۶. کل متن زیر را یک‌جا کپی و اجرا کنید:

```powershell
$ErrorActionPreference = "Stop"

$isAdmin = (
    New-Object Security.Principal.WindowsPrincipal(
        [Security.Principal.WindowsIdentity]::GetCurrent()
    )
).IsInRole(
    [Security.Principal.WindowsBuiltInRole]::Administrator
)

if (-not $isAdmin) {
    throw "PowerShell must run as Administrator."
}

$panelHost = "pannel.tiara.internal"
$panelIp = "192.168.1.208"
$certPath = Join-Path $env:USERPROFILE "Downloads\tiara-internal-root-ca.cer"
$expectedHash = "6B94E39DEE4FAAA675F489E105442090840C68C8A8E5333A974D121A1BA8397B"

if (-not (Test-Path -LiteralPath $certPath -PathType Leaf)) {
    throw "Certificate file not found in Downloads."
}

$actualHash = (Get-FileHash -LiteralPath $certPath -Algorithm SHA256).Hash

if ($actualHash -ne $expectedHash) {
    throw "Certificate hash is wrong. Stop and contact IT."
}

certutil.exe -addstore Root $certPath

if ($LASTEXITCODE -ne 0) {
    throw "Certificate install failed."
}

$hostsFile = "$env:WINDIR\System32\drivers\etc\hosts"
$hostsBackup = "$hostsFile.dolphin-$(Get-Date -Format yyyyMMddHHmmss).bak"

Copy-Item -LiteralPath $hostsFile -Destination $hostsBackup

$activeLines = @(
    Get-Content -LiteralPath $hostsFile |
    Where-Object { $_ -notmatch '^\s*#' }
)

$validPattern = '^\s*192\.168\.1\.208\s+pannel\.tiara\.internal(?:\s|$)'
$anyPattern = '^\s*\d{1,3}(?:\.\d{1,3}){3}\s+pannel\.tiara\.internal(?:\s|$)'

$validLines = @(
    $activeLines |
    Where-Object { $_ -match $validPattern }
)

$wrongLines = @(
    $activeLines |
    Where-Object {
        $_ -match $anyPattern -and
        $_ -notmatch $validPattern
    }
)

if ($wrongLines.Count -gt 0) {
    throw "A wrong panel address already exists. Contact IT."
}

if ($validLines.Count -eq 0) {
    Add-Content `
        -LiteralPath $hostsFile `
        -Value "`r`n192.168.1.208 pannel.tiara.internal"
}

ipconfig.exe /flushdns

$resolvedAddresses = @(
    [System.Net.Dns]::GetHostAddresses($panelHost) |
    ForEach-Object { $_.IPAddressToString }
)

if ($resolvedAddresses -notcontains $panelIp) {
    throw "Panel name did not resolve to the correct server."
}

Write-Host "Dolphin setup completed successfully." -ForegroundColor Green

Start-Process "https://pannel.tiara.internal/"
```

## نتیجه درست

باید این پیام دیده شود:

```text
Dolphin setup completed successfully.
```

سپس صفحه ورود دلفین باز می‌شود.

آدرس همیشگی پنل:

```text
https://pannel.tiara.internal/
```

از IP استفاده نکنید.

اگر مرورگر هشدار certificate نشان داد، روی ادامه‌دادن نزنید. مرورگر را ببندید و با مسئول فنی تماس بگیرید.
